# BiologicalAGI-Hub

## Purpose

BiologicalAGI-Hub is intended to serve as the central orientation hub for selected BiologicalAGI and SCOS-related projects. It provides a high-level map for understanding the ecosystem, navigating related repositories, and reviewing documentation safely.

## Current Status

**Documentation Draft / Review-Only**

This repository does not provide runtime functionality, automation, production services, active AI agents, or deployment tooling. It is intended for documentation, navigation, and ecosystem orientation only.

## Intended Audience

- Developers interested in BiologicalAGI and SCOS-related projects.
- Contributors seeking a high-level overview of the ecosystem.
- General users exploring the purpose, structure, and boundaries of the BiologicalAGI initiative.

## What This Repo Contains

This repository is intended to contain:

- Links to selected BiologicalAGI and SCOS-related repositories as the hub is refined.
- A plain-language overview of the ecosystem’s structure and relationships.
- Guidance for safe exploration and documentation review.
- [Public Glossary](docs/BIOLOGICALAGI_PUBLIC_GLOSSARY_V0_1.md): high-level public-safe terms and orientation.
- [Public Contribution Index](docs/PUBLIC_CONTRIBUTION_INDEX.md): evidence-based status map for selected public work and drafts.
- Future contribution and collaboration guidelines after review.

## Relationship to SCOS

This repository operates as a high-level documentation and orientation surface within the broader SCOS ecosystem. It supports SCOS principles such as:

- orientation before execution
- evidence before claims
- consent before action
- handoff before automation

This hub does not activate SCOS runtime behavior. It helps users understand where related projects fit and what is safe to review.
